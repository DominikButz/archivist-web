# Sharing

## 1. Sharing the PDF File


To easily share the PDF file of a document, simply click or tap the
share button in the document view. This will open the share sheet where
you can choose from various options. For example, you can send the file
via email or iMessage, or even print it
using an air-print compatible printer on iOS
and iPadOS.

Additional sharing options can be selected in the pop-up-menu after
tapping or clicking on the "more options" button on the bottom toolbar
(iOS / iPadOS) or in the top bar of the document view (MacOS).

![](media/sharingMoreOptions.png)

On MacOS, this pop-up menu includes an option to print the PDF file. On
iOS / iPadOS however this option is included in the share button menu.
The "more options" menu also allows you to paste the page text to the OS
clipboard, show the location of the document PDF file in iCloud Drive
and to open the PDF file in the default PDF app (this last option is
only available on MacOS).

## 2. Sharing an archive drawer


While Archivist does not support direct sharing of single documents through iCloud, it does provide a convenient way to share an entire archive drawer along with all its documents. Sharing individual
documents via iCloud would involve sending share links repeatedly, which can be cumbersome. Instead, you can easily share a custom archive drawer with another user using the following steps.

To share a custom drawer, press (iOS/iPadOS) or right-click (MacOS) on the archive drawer icon to open the context menu. From there, select the \"share settings\" option. This will open the share settings view.

![](media/shareControllerView.png)

In the share settings view, you can choose to \"Share With More People\" by adding recipients through email, iMessage, or other messenger apps.
The recipient will receive a message containing a URL that, when clicked or tapped, will automatically open Archivist and display the shared drawer in the \"Archive Drawers\" tab view.

Within the share settings view, as shown in the screenshot, you can also define the level of access for participants. Participants can either have read-only access or be allowed to edit certain document details such as the date and text fields (title, content, comment).
However, only the document owner can edit other properties like topics, drawer, and document type. Once at least one participant has been added, the shared drawer will display a shared icon in the top left corner, as depicted in the screenshot.

When a recipient views the shared drawer, they will see a \"shared from\" icon in the top left corner, along with the name of the drawer owner below the drawer name.
Documents that are shared with other users will display the shared icon above the document title in the document cell of the documents list.
Conversely, documents shared by other users will show the \"shared
with\" icon above the document title.

To manage participants, remove users, or stop sharing the drawer, simply select the share settings option in the drawer\'s context menu. If you are a participant in a shared drawer and wish to end your participation, you can access the shared settings (as mentioned above) and choose the appropriate option to leave the shared drawer.
