# Adding and Editing Document Attribute Labels


There are three types of attribute labels available in the application:
Archive Drawers, Topics, and Document Types. Each type has its own
dedicated tab section. On iOS / iPadOS these tabs are in the main app window, however on MacOS, the attribute label lists can be found in a separate window that can be opened from the task bar or by clicking on the drawer button in the top area of the main app window.
![](/media/docLabelLayoutSortingOptions.png)

To access the options related to attribute labels, simply tap or click on the options button. This will bring up a menu with various filter and layout options. For example, the screenshot provided illustrates the options available for the document types list. Both document types and topics lists offer two layout options: \"Alphabetical\" and \"Document count.\" However, the layout option for the drawer list is limited to the descending document count layout.

When you first launch Archivist, the system automatically creates system drawers, topics, and document types. While there are numerous system topics and document types available, there are only two system drawers: \"Private\" and "Trash\". System drawers cannot be deleted.

To add a custom attribute item, simply press the \"Plus\" button. Please ensure that the item name is unique and does not match any existing attribute items.

Both drawers and document types have a default item since every new
document must belong to a drawer and have a document type. You can
change the default item by selecting the \"Set as Default\" option in the context menu. On iOS/iPadOS, simply tap on the item icon to open the context menu, while on MacOS, right-click to access it.

![](/media/drawerContextMenu.png)

If the attribute item is a custom item, the context menu also provides options to delete and rename the item. However, please note that the deletion option will only appear if the item does not have any associated documents.

Deleted system topics and document types can be restored in settings - simply open the "Restore System Items" view in the first section.

Archive drawers have an additional option called "share settings". For more information on this feature, please refer to the \"Sharing\" section.
