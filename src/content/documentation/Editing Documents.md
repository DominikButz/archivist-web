# Editing Documents

To edit the document data, select the document in the document list of
the "Archive" tab and press the pencil button on the bottom right on iOS
/ iPadOS or click on the column-reveal button on the right side of the
document view on MacOS.

If you are the owner of the document, you can edit all document
properties except for the meta-data shown at the bottom of the form.

In case a document is shared with you and the owner has granted write
access, only the following properties are editable:

-   Title
-   Document Date
-   ID
-   Text Content
-   Comment


If you only have read-access, none of the properties are editable. Check
out the section on sharing below for details.

The editing view allows you to change the document attributes such as
"Archive Drawer", "Topics" and "Document Type". A document can only be
part of one drawer and have one document type but it can have several
topics assigned to it or no topic at all.

After making changes to one or several document properties, you need to
click or tap the \"Save\" button for the changes to be persisted. If you
want to undo the changes, you can press the \"Reset\"
button.

The document view also allows editing the PDF document itself. To rotate
a page clockwise, click or tap the "rotate" button on the PDF page
view.

You can also add, delete and rearrange the PDF pages in the thumbnail
view. To open the page thumbnail view, tap or click on the thumbnail
button (in the top left corner on MacOS or on the bottom toolbar on iOS
/ iPadOS).

The "+Pages" button allows you to append the PDF file
by selecting another PDF file or one or several images.

Additionally, on MacOS, the thumbnail view includes an additional button
as last thumbnail item - you can click it to add pages and drop files
onto the button.

Each page thumbnail has a delete button in the top right corner. Press
the button to remove the page. However, if the document only has one
page, the delete button will not be shown.

To rearrange the order of the PDF pages, long-press or long-click on the
page, then drag it to the desired position.

All changes can be undone by selecting the "Restore" button or saved by
clicking or tapping the "Save" button.

**Important:** some PDF files, such as official documents, may not allow
adding, deleting, or rotating pages. In such cases, the respective
buttons will be greyed out and unavailable for use.

## Making changes in the Document List

Bring up the context menu by long pressing (iOS / iPadOS) or
right-clicking (MacOS) on a document cell in the document list of the
"Archive". The context menu includes the following
options:

-   Bookmark or Remove from Bookmarks
-   Move document (to another drawer)
-   Start AI detection
-   Move to trash

![](/media/docCellContextMenu.jpeg)

Alternatively, you can swipe left or right on the document cell to
reveal the \"Add to
bookmarks\" and \"Move to trash\" buttons.

Please note that the option **"Start AI detection"** is only available if document properties haven't been set through AI before, e.g. because auto-AI detection (on document creation) is switched off in the settings. If you prefer AI detection to be switched off by default, the option "Start AI detection" allows you to trigger AI detection for some documents only. 

The navigation bar on the top of the documents list view contains an
edit button. Clicking or tapping this button will toggle the document
list edit mode. In edit mode, you can select one or several documents by
activating the check mark that appears
on the left of each document cell.

Once selected, you can perform the following actions using the buttons
in the navigation bar:

- move the selected documents to another drawer or 
- move the selected documents to the trash bin.

To exit the edit mode, press the \"Done\" button in the navigation
bar.

If a document is in the trash bin, the context menu for that document
will be different:

-   Delete: permanently deletes the document, including the PDF file

-   Restore: moves the document back to its original drawer

-   Move document: allows moving the document to another drawer, thereby
    restoring it.
